# Промпт

Для тех, у кого не Claude Code, а другой ИИ-помощник с доступом к терминалу (Codex, Gemini CLI,
Cursor и т. п.). Скачай или склонируй этот репозиторий, открой помощника **в его папке** и вставь
текст ниже. Владельцам Claude Code проще — см. README, там одна команда.

---

Я хочу очистить Android-телефон от предустановленного мусора и рекламы через ADB.
Телефон: <марка и модель, например Redmi Note 14>. Для кого: <для себя / для мамы / для ребёнка>.

Открой файл `skills/debloat-phone/SKILL.md` в этой папке и веди меня по нему строго по шагам,
от «Шаг 1 из 10» до «Шаг 10 из 10». Я могу никогда не пользоваться ADB — объясняй каждое
действие простыми словами и жди моего ответа после каждого шага.

Правила, которые нельзя нарушать:
- ничего не удалять, пока я не утвердил список;
- никогда не трогать пакеты из `skills/debloat-phone/lists/protected.txt`;
- приложения, которые я ставил сам, не удалять, если я сам их не назову;
- удалять только `pm uninstall -k --user 0` (обратимо), без root и прошивки;
- сначала бэкап списка пакетов, в конце — как всё вернуть;
- в файлах и отчётах не писать мои IP-адреса, серийные номера, e-mail и имена Wi-Fi.
