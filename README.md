# Clean Your Phone

**Русский** | [English](README.en.md)

Пошаговая очистка Android-телефона от предустановленного мусора и рекламы через ADB — вместе с
ИИ-помощником. Без root, без прошивки, всё обратимо.

Сделано в первую очередь для **Xiaomi / Redmi / POCO (HyperOS, MIUI)** — там рекламы больше
всего, — но работает почти на любом Android: Samsung, realme, OPPO, Motorola, Pixel и т. д.

## Что получится

- Нет рекламы в системных приложениях, на экране блокировки и в «рекомендациях».
- Телефон больше сам не докачивает игры и «партнёрские» приложения.
- Удалены предустановленные игры, дубли производителя (браузер, музыка, видео, «Очистка»).
- Звонки, SMS, камера, галерея, Play Маркет, браузер и всё, что вы поставили сами, — на месте.

## Как это выглядит

Помощник ведёт по 10 шагам и после каждого ждёт вашего ответа:

1. Что понадобится (компьютер, кабель или Wi-Fi, программа adb)
2. Включаем режим разработчика — инструкция под вашу марку
3. Подключаем телефон — кабелем или по Wi-Fi с кодом
4. Бэкап и знакомство с телефоном: что поставил производитель, а что вы сами
5. Чем вы пользуетесь из того, что обычно считают мусором
6. **Глубина очистки:** только реклама / стандарт / максимум / свой список
7. Показывает список человеческими словами и ждёт вашего «да»
8. Удаляет и проверяет, что звонки, SMS и камера работают
9. Открывает на телефоне нужные экраны и говорит, какой переключатель выключить
10. По желанию: блокировка рекламы через DNS, 60 Гц и анимации для батареи; как всё вернуть

Займёт 20–40 минут. Ответить придётся на 4–6 вопросов.

## Как запустить

### Claude Code (одна команда)

Установить один раз:

```
/plugin marketplace add posp3h/cleanyourphone
/plugin install cleanyourphone@cleanyourphone
```

Запускать (подключать телефон не обязательно — помощник сам скажет, когда):

```
/cleanyourphone:debloat-phone
```

Или просто напишите: «почисти мой телефон Redmi от рекламы».

> Без установки плагина: склонируйте репозиторий и скопируйте папку `skills/debloat-phone` в
> `~/.claude/skills/` (Windows: `%USERPROFILE%\.claude\skills\`). Команда будет `/debloat-phone`.

### Другие ИИ-помощники

Склонируйте репозиторий, откройте помощника в его папке и вставьте текст из [PROMPT.md](PROMPT.md).

## Безопасность

- Приложения удаляются только для пользователя (`pm uninstall -k --user 0`): файл остаётся в
  прошивке, вернуть можно одной командой или сбросом к заводским настройкам.
- Список «не трогать никогда» — [protected.txt](skills/debloat-phone/lists/protected.txt).
  Скрипт откажется работать, если в план попадёт что-то оттуда.
- Ничего не удаляется без вашего подтверждения. Приложения, которые вы поставили сами, не
  предлагаются к удалению.
- Журнал всех действий сохраняется; [restore](skills/debloat-phone/scripts/) возвращает всё.

## Вернуть приложение

```
adb shell cmd package install-existing <имя.пакета>   # удалённое
adb shell pm enable <имя.пакета>                      # отключённое
```

Или всё сразу: `scripts/restore.ps1 -Serial <телефон> -Log backups/.../uninstall-log.tsv`.

## Что внутри

| Путь | Что это |
|---|---|
| `skills/debloat-phone/SKILL.md` | Сценарий из 10 шагов — его читает помощник |
| `skills/debloat-phone/lists/` | Списки пакетов по уровням: Xiaomi, Google, партнёрские приложения, защищённые |
| `skills/debloat-phone/scripts/` | `apply` — применить план, `restore` — вернуть, `origin` — кто поставил приложение |
| `examples/` | Реальные очищенные телефоны: что удалили, что всплыло |
| `PROMPT.md` | Текст для других ИИ-помощников |

Добавить свой телефон в `examples/` — по образцу [redmi-17-hyperos3.md](examples/redmi-17-hyperos3.md),
без IP-адресов, серийных номеров и имён аккаунтов.
