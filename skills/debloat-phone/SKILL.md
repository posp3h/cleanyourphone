# Очистка Android-телефона через ADB — пошагово

Ты ведёшь человека, который, возможно, никогда не пользовался ADB. Он видит телефон, ты видишь
только то, что отвечает `adb`. Работай как терпеливый мастер у кухонного стола.

## Как вести сессию (обязательно)

- **Говори на языке пользователя.** Внутри команд — английский, в объяснениях — его язык.
- **Каждый шаг оформляй одинаково:** заголовок `Шаг N из 10 — <название>`, одна-две фразы
  «зачем это», потом действия нумерованным списком, потом «что должно получиться».
  Не вываливай следующий шаг, пока текущий не подтверждён.
- **Вопросы с вариантами** задавай через инструмент вопросов с кнопками (AskUserQuestion или
  аналог), если он есть; иначе — нумерованным списком «ответь цифрой».
- **Ничего не удаляй, пока человек не утвердил список.** Утверждение одного списка не
  распространяется на следующий.
- **Проверяй, а не предполагай.** После каждого действия смотри результат (`pm list packages`,
  `dumpsys`, запуск приложения). Пишешь «готово» только то, что проверил.
- **Ничего не придумывай про пакеты.** Если не знаешь, что делает пакет, посмотри
  `dumpsys package <pkg>` (activities, services, permissions) и спроси. Неизвестное — не трогаем.
- **Секреты.** Не вставляй в отчёты и файлы IP-адреса, серийные номера, имена Wi-Fi, e-mail
  аккаунтов. В файлах используй `<phone ip>`.
- Сохраняй все артефакты в папку `backups/<модель>-<ГГГГ-ММ-ДД>/` в рабочей директории.

Файлы рядом с этим SKILL.md:

| Файл | Что это |
|---|---|
| `lists/protected.txt` | **Никогда не трогать.** Удаление ломает загрузку, звонки, SMS, Play. |
| `lists/xiaomi.txt` | Xiaomi/Redmi/POCO (HyperOS/MIUI), с уровнем и пояснением на каждый пакет. |
| `lists/google.txt` | Приложения Google, которые обычно можно убрать. |
| `lists/partners.txt` | Партнёрские приложения и игры, которые производители ставят за деньги. |
| `scripts/apply.sh`, `scripts/apply.ps1` | Применяет утверждённый список, пишет журнал, сам переходит на «отключить», если удалить нельзя. |
| `scripts/restore.sh`, `scripts/restore.ps1` | Возвращает всё по журналу. |
| `scripts/origin.sh`, `scripts/origin.ps1` | Делит сторонние приложения: поставил телефон / докачал при настройке / поставил пользователь. |

## Шаг 1 из 10 — Что понадобится

Объясни и проверь:

1. Компьютер (Windows / macOS / Linux) и телефон, заряженный хотя бы на 50%.
2. **Android Platform Tools (adb).** Проверь `adb version`. Если нет:
   - Windows: `winget install Google.PlatformTools`
   - macOS: `brew install android-platform-tools`
   - Linux: `sudo apt install adb` (или пакет своего дистрибутива)
   - Или вручную: https://developer.android.com/tools/releases/platform-tools
3. Кабель USB **с передачей данных** (у некоторых кабелей есть только зарядка) — или общий Wi-Fi
   для беспроводного подключения (Android 11+).
4. Предупреди: всё делаем только для основного пользователя телефона, без root и без прошивки.
   Сброс к заводским настройкам вернёт всё как было; кроме того, каждое удалённое приложение
   возвращается одной командой.

## Шаг 2 из 10 — Включаем режим разработчика

Спроси марку телефона, если не знаешь, и дай инструкцию именно для неё:

| Марка | Где нажать 7 раз | Где потом «Для разработчиков» |
|---|---|---|
| Xiaomi / Redmi / POCO (HyperOS) | Настройки → О телефоне → **Версия ОС** (на некоторых: «Подробная информация» → «Версия ОС») | Настройки → Дополнительные настройки → Для разработчиков |
| Xiaomi (MIUI 12–14) | О телефоне → **Версия MIUI** | Расширенные настройки → Для разработчиков |
| Samsung | Сведения о телефоне → Сведения о ПО → **Номер сборки** | внизу главного списка настроек |
| Google Pixel, Motorola, Nokia | О телефоне → **Номер сборки** | Система → Для разработчиков |
| OnePlus / OPPO / realme | Об устройстве → Версия → **Номер сборки** | Доп. настройки → Для разработчиков |
| Honor / Huawei | О телефоне → **Номер сборки** | Система и обновления → Для разработчиков |

Затем в «Для разработчиков» включить **«Отладка по USB»**.

**Для Xiaomi отдельно расскажи про «Отладка по USB (настройки безопасности)»:**
- Без неё: удалять и отключать приложения МОЖНО. НЕЛЬЗЯ: менять защищённые настройки
  (`settings put global/secure`), нажимать на экран через ADB, отзывать разрешения.
  Это не страшно — такие настройки человек сделает руками, а ты откроешь ему нужный экран.
- Для её включения Xiaomi требует SIM-карту и вход в Mi-аккаунт. Обходов без root нет
  (`setprop persist.security.adbinput 1` из shell запрещён). Не уговаривай заводить аккаунт.

## Шаг 3 из 10 — Подключаем телефон

Спроси, как удобнее, и веди по одному варианту:

**А. Кабель (надёжнее).**
1. Подключить, в шторке выбрать режим USB «Передача файлов».
2. На телефоне появится «Разрешить отладку по USB?» → отметить «Всегда разрешать» → «Разрешить».
3. Ты: `adb devices -l` → должно быть `device` (не `unauthorized`).
   - Пусто на Windows: проверь `Get-PnpDevice -PresentOnly | ? FriendlyName -match 'Android|ADB'`;
     другой кабель/порт, режим «Передача файлов».

**Б. Wi-Fi (Android 11+, без кабеля).**
1. «Для разработчиков» → **«Отладка по Wi-Fi»** → включить.
2. Внутри → **«Подключить с кодом сопряжения»**. Человек диктует IP:порт **из этого окна** и 6-значный код.
3. Ты: `adb pair <ip>:<порт сопряжения> <код>`.
4. Затем порт с главного экрана «Отладки по Wi-Fi» (он другой!): `adb connect <ip>:<порт>`.
5. «failed to connect» при открытом порте = ещё не было сопряжения. Порт меняется при каждом
   включении отладки по Wi-Fi; повторное сопряжение после этого не нужно — только новый порт.

Если подключено несколько устройств — всегда `adb -s <serial>`.

## Шаг 4 из 10 — Знакомимся с телефоном и делаем бэкап

```
adb shell getprop ro.product.marketname   # или ro.product.model
adb shell getprop ro.build.version.release
adb shell getprop ro.mi.os.version.name    # HyperOS; для MIUI: ro.miui.ui.version.name
adb shell getprop ro.build.version.incremental
adb shell pm list packages -f -u   > packages-all-before.txt
adb shell pm list packages -3      > packages-3rd-before.txt
adb shell pm list packages -d      > packages-disabled-before.txt
adb shell cmd role get-role-holders android.app.role.DIALER
adb shell cmd role get-role-holders android.app.role.SMS
adb shell cmd role get-role-holders android.app.role.HOME
adb shell cmd role get-role-holders android.app.role.BROWSER
```

Затем раздели сторонние приложения по происхождению — `scripts/origin.ps1 -Serial <s> -Out
origin.tsv` (или `origin.sh <s> > origin.tsv`):

| origin | Что значит | Как поступаем |
|---|---|---|
| `preinstalled` | лежит в прошивке или поставлено магазином производителя/оператора | кандидат на удаление по уровню |
| `setup-autoinstall` | докачано в первые 2 часа (при первой настройке: GetApps, «рекомендуемые» Play) | кандидат, но покажи отдельной группой и спроси |
| `user` | человек сам поставил из Play Маркета | **не предлагать к удалению**. Только показать списком «ваши приложения», трогать — лишь если человек сам назовёт |
| `sideload` | установлен файлом APK | не трогать, спросить |
| `unknown` | не определилось | спросить |

На телефоне, которым уже пользуются (есть аккаунты, человек сам ставил игры), это главное правило:
**игры и приложения, которые человек поставил сам, — его, а не мусор**, даже если выглядят как
предустановленные. Осторожно с `setup-autoinstall`: если при настройке человек восстанавливал
приложения из резервной копии Google, его собственные приложения тоже попадут сюда. Данные
приложений без root через ADB не видны, поэтому при любом сомнении — спрашивай.

Проверь, какие права есть у ADB (от этого зависят шаги 9–10):
```
adb shell settings put global cyp_probe 1 && adb shell settings delete global cyp_probe
```
Успех — «настройки безопасности» включены (или это не Xiaomi): DNS, анимации и т. п. можно менять
командами. `SecurityException` — только руками, ты открываешь экраны. Также узнай, есть ли аккаунты:
`dumpsys account | grep -E 'Accounts:|Account \{' ` (только тип аккаунта, адреса не выводи в отчёт).
Если Google-аккаунт есть — нужные приложения в конце можно ставить через Play сразу; если есть
Mi-аккаунт — можно включить «настройки безопасности» и делать больше через ADB.

Сохрани всё в `backups/<модель>-<дата>/`. Расскажи человеку коротко: модель, версия Android и
оболочки, сколько всего пакетов, сколько «сторонних», какие приложения сейчас отвечают за звонки,
SMS, рабочий стол и браузер. **Пакеты, держащие эти роли, — в защищённые** до конца сессии
(например, если звонилка `com.google.android.dialer`, её не удаляем, даже если она в списке).

## Шаг 5 из 10 — Что важно человеку (до любых списков)

Спроси (кнопками, можно несколько вариантов):

1. **Для кого телефон?** Для себя / для пожилого человека / для ребёнка. Для пожилого — меньше
   приложений, но ничего, к чему он привык (лаунчер, звонилка) не менять без спроса.
2. **Чем пользуются из того, что часто считается мусором?** Список собери из реально установленного:
   соцсети (Instagram, Facebook, TikTok), музыка (Spotify, YouTube Music), Mi Fitness/браслет,
   FM-радио, погода, календарь производителя, Gmail, Google Фото, Google Диск, Gemini,
   ShareMe/Quick Share, Mi Home и т. п. Отмеченное — в исключения.
3. **Можно ли заходить в аккаунты** (Google, Mi)? Влияет на то, что сможем поставить в конце.

## Шаг 6 из 10 — Выбираем глубину очистки

Предложи четыре варианта (кнопками) и объясни разницу простыми словами:

| Уровень | Что делаем | Для кого |
|---|---|---|
| **1. Только реклама** | Отключаем (не удаляем) рекламные и аналитические сервисы, автоустановку приложений, карусель обоев на экране блокировки, ленты рекомендаций. Все приложения остаются. | Кто боится что-то сломать или пользуется приложениями производителя |
| **2. Стандарт** (рекомендуется) | Уровень 1 + удаляем предустановленные игры и партнёрские приложения, дубли производителя с рекламой (браузер, музыка, видео, «Очистка», магазин приложений). | Большинство |
| **3. Максимум** | Уровень 2 + лишние приложения Google, сервисы производителя, без которых телефон работает (перенос данных, сканер, компас, обратная связь, обновление встроенных приложений). | Минимализм, телефон «звонки + камера + мессенджеры» |
| **4. Свой список** | Показываю всё найденное по категориям, человек сам отмечает. | Опытные |

На любом уровне действуют исключения из шага 5 и защищённый список.

## Шаг 7 из 10 — Составляем список и согласовываем

1. Возьми все установленные пакеты (`pm list packages`) и сопоставь:
   - `lists/protected.txt` — выкинуть из рассмотрения полностью;
   - `lists/xiaomi.txt`, `lists/google.txt`, `lists/partners.txt` — у каждой строки уровень
     `L1/L2/L3` и действие `disable`/`uninstall`; берём строки с уровнем ≤ выбранного;
   - сторонние приложения (`-3`), которых нет в списках, — это обычно партнёрские игры/приложения:
     опиши каждое по названию (`dumpsys package <pkg> | grep -m1 versionName`, имя пакета) и
     отнеси к L2;
   - для других производителей (Samsung, Oppo, realme, Transsion…) классифицируй сам по тем же
     категориям. Можно свериться со списком проекта Universal Android Debloater Next Generation
     (https://github.com/Universal-Debloater-Alliance/universal-android-debloater-next-generation,
     файл `resources/assets/uad_lists.json`) — бери только пакеты с пометкой `Recommended`,
     пометки `Advanced`/`Expert`/`Unsafe` — только на уровне 4 и с объяснением рисков.
2. Убери исключения из шага 5, держателей ролей из шага 4 и всё с `origin = user` / `sideload`.
   Если пакет есть в списке мусора, но `origin = user` (человек сам поставил TikTok) — он остаётся.
3. Запиши итог в `backups/.../plan.txt` (одна строка — один пакет, `#` — комментарий-группа).
4. Покажи человеку **по группам**, человеческими названиями, а не только именами пакетов:
   «Игры (11): Маджонг, Wood Blast…», «Реклама Xiaomi: msa — рекламный сервис, показывает баннеры
   во всех приложениях Xiaomi» и т. д. Отдельным блоком «Оставляем» — что точно остаётся.
5. Задай 1–3 уточняющих вопроса по спорным пунктам (погода, календарь, радио…) и дождись «да».

Объясни заранее, что Погоду производителя лучше оставить: от неё зависят виджет «часы+погода» и
погода на экране блокировки; реклама в ней уходит вместе с рекламным сервисом.

## Шаг 8 из 10 — Удаляем и проверяем

1. Применяй скриптом: `scripts/apply.sh <serial> plan.txt` (macOS/Linux) или
   `scripts/apply.ps1 -Serial <serial> -Plan plan.txt` (Windows). Он:
   - удаляет `pm uninstall -k --user 0` (обратимо: `cmd package install-existing <pkg>`),
     а строки с пометкой `disable` — `pm disable-user --user 0`;
   - если удалить нельзя (`Failure [-1000]` — защита Xiaomi), сам отключает;
   - по одному пакету на вызов, журнал `uninstall-log.tsv` рядом с планом.
   Большие списки разбивай на 2–3 партии (реклама → игры → остальное), проверяя между ними.
2. После каждой партии проверь, что живо главное:
   ```
   adb shell monkey -p <pkg> -c android.intent.category.LAUNCHER 1
   ```
   для звонилки, SMS, камеры, галереи, Play Маркета, браузера и рабочего стола (`am start -a
   android.intent.action.MAIN -c android.intent.category.HOME`). `Events injected: 1` — ок.
   Посмотри `adb shell logcat -d -b crash | grep 'Process:'` — падения удаляемых в этот момент
   приложений (Spotify и т. п.) нормальны, падения системных — нет: верни последнюю партию.
3. Покажи итог: удалено N, отключено M, не получилось K (с причиной).

## Шаг 9 из 10 — Реклама в оставшихся системных приложениях

Часть переключателей можно сменить только руками. Не перечисляй путь по меню — **открой нужный
экран сам** и скажи, куда нажать. Найти экран: `dumpsys package <pkg> | grep -o '<pkg>/[A-Za-z0-9_.$]*Setting[A-Za-z0-9_.$]*'`,
открыть: `am start -n <pkg>/<activity>`. Если `am start` даёт `Permission Denial` — экран
открывается только с телефона, объясни путь словами.

Для Xiaomi (HyperOS 3, проверено):

| Приложение | Экран | Что выключить |
|---|---|---|
| Темы | `com.android.thememanager/.activity.ThemeSettingsActivity` | «Показывать рекламу», «Персональные рекомендации» |
| Безопасность | `com.miui.securitycenter/com.miui.securityscan.ui.settings.SettingsActivity` | «Получать рекомендации» (после удаления msa его может не быть — это нормально) |
| Погода | `com.miui.weather2/.ActivityWeatherMain` → ⋮ → Настройки | всё про новости/контент (в свежих версиях этого уже нет) |
| Проводник | запуск приложения → ☰ → Настройки | «Получать рекомендации» |
| Рабочий стол | `com.miui.home/.settings.MiuiHomeSettingActivity` | рекомендации в папках, «-1 экран»/ленту (в упрощённом режиме этих пунктов нет) |
| Реклама Google | `com.google.android.gms/.adsidentity.settings.AdsIdentitySettingsActivity` | «Удалить рекламный идентификатор»; «Конфиденциальность рекламы» → всё выкл. |
| Экран блокировки | Настройки → Экран блокировки | если остался значок/лента карусели — обычные обои |

Для Samsung: Настройки → Конфиденциальность → Службы настройки (выкл.), Galaxy Store → настройки →
маркетинговые уведомления (выкл.), Samsung Free / Samsung Daily — отключить. Другие марки: ищи
«рекомендации», «персонализированный контент», «реклама» в настройках системных приложений.

## Шаг 10 из 10 — Дополнительно и завершение

Предложи по желанию (каждое — отдельный вопрос):

- **Блокировка рекламы через DNS** (AdGuard): Настройки → Подключение и общий доступ (или «Сеть и
  интернет») → Частный DNS-сервер → `dns.adguard-dns.com`. **Обязательно предупреди:** в режиме
  «Имя хоста» при недоступности сервера (блокировка в стране, у оператора, в поездке) пропадает
  интернет целиком — звонки и SMS работают. Для пожилых людей без помощника рядом рекомендуй
  оставить «Автоматически». Проверка, что работает: `dumpsys connectivity | grep -o
  'PrivateDnsServerName: [^ ]*'` и `ValidatedPrivateDnsAddresses`. Через ADB поставить можно только
  при включённых «настройках безопасности» (`settings put global private_dns_mode hostname` +
  `private_dns_specifier`), иначе — открой экран
  `com.android.settings/.network.PrivateDnsSettingsActivity`.
- **Батарея и плавность:**
  - частота экрана 60 Гц (работает без «настроек безопасности» на Xiaomi):
    `settings put system miui_refresh_rate 60`, `user_refresh_rate 60`, `peak_refresh_rate 60`,
    `min_refresh_rate 60`, `is_smart_fps 0`; проверка `dumpsys display | grep mActiveRenderFrameRate`.
    Другие марки: `settings put system peak_refresh_rate 60` и `min_refresh_rate 60`;
  - анимации 0,5x: «Для разработчиков» → Отрисовка → три пункта «Анимация…» → 0,5x
    (или `settings put global window_animation_scale 0.5` и т. д., если есть права);
  - фон приложениям не ограничивай без просьбы: мессенджеры начнут опаздывать с уведомлениями.
- **Упрощённый режим** (Xiaomi: Настройки → Специальные возможности/Упрощённый режим) — для
  пожилых. Учти: после него может выключиться режим разработчика
  (`settings get global development_settings_enabled` = 0) — тогда человек снова нажимает 7 раз.
- **Лаунчер** не меняй, если человек привык к стоковому: скорости почти не прибавит (стоковый всё
  равно работает под жестами и «Недавними»), а привычку сломает.

Завершение:

1. Итоговое резюме: что удалено/отключено, что выставлено руками, что осталось сделать (аккаунты,
   установка нужных приложений через Play).
2. Как вернуть: `scripts/restore.ps1 -Serial <serial> -Log uninstall-log.tsv` / `restore.sh`, или
   одно приложение: `adb shell cmd package install-existing <pkg>` (отключённое:
   `adb shell pm enable <pkg>`). Сброс к заводским вернёт всё.
3. Предложи выключить «Отладку по Wi-Fi» (и «Отладку по USB», если телефон уходит человеку).

## Известные подвохи (из реальных сессий)

- **Xiaomi `Failure [-1000]`** при удалении ShareMe, Сканера, Компаса, Записи экрана — защита.
  Скрипт отключает их вместо удаления; с экрана они пропадают.
- **Вкладка «Обновление» в Настройках Xiaomi** — это обновление встроенных приложений
  (`com.xiaomi.discover`), а не прошивки. Если discover удалён (уровень 3), вкладка не открывается.
  Прошивка обновляется через логотип HyperOS в «О телефоне» (`com.android.updater` не трогаем).
  Без discover встроенные приложения Xiaomi обновляются только с прошивкой. Предупреди заранее.
- **`settings put global …` → SecurityException, `input keyevent` → INJECT_EVENTS** — нет «настроек
  безопасности». `settings put system …`, `am start`, `pm uninstall/disable-user` при этом работают.
- **`screencap` может отдавать пустой/обрезанный кадр.** Не полагайся на скриншоты — спрашивай
  человека, что он видит, или проверяй через `dumpsys activity activities | grep topResumedActivity`.
- **Без Google-аккаунта Play Маркет ничего не ставит.** Не предлагай качать APK со сторонних
  сайтов для чужого телефона: такие приложения не обновляются сами.
- **Wi-Fi ADB отваливается** после перезапуска adb-сервера или сна телефона: `adb connect <ip>:<порт>`
  ещё раз; если порт сменился — спроси новый.
- **Нельзя удалять на Xiaomi** (бутлуп или потеря функций): `com.miui.securitycenter`,
  `com.lbe.security.miui`, `com.miui.securitycore`, `com.miui.guardprovider`, `com.miui.home`
  (если не стоит другой лаунчер), `com.miui.system`, `com.miui.rom`, `com.miui.core`,
  `com.xiaomi.xmsf` (пуш-уведомления), `com.miui.powerkeeper`, `com.android.updater`. Всё это есть
  в `lists/protected.txt`.
